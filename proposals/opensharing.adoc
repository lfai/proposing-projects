* *Project description* (what it does, why it is valuable, origin and history, ongoing development).
+
OpenSharing is a cross-platform, vendor-neutral protocol for zero-copy sharing of
Data and AI assets. It defines one discovery API, one credential-vending model,
and one access-control model across tables (Delta, Iceberg, Parquet), volumes
(directories of files in any format), AgentSkills, and Models — with Agent and
Page asset types under community proposal. Any compliant server can share to any
compliant client; there is no required SDK and no required platform.
+
It is valuable because sharing across organizational boundaries is still
point-to-point plumbing: custom integrations per partner, manual copies,
catalog/format fragmentation (Delta vs. Iceberg), and — critically — no standard
at all for the assets that now matter most (models, agents, agent skills), nor
for regulated or on-premises data that cannot move. A sharing protocol is the one
component of the AI/data stack that structurally cannot be single-vendor, which
is why it belongs in a neutral foundation.
+
*Origin and history:* OpenSharing generalizes Delta Sharing (open-sourced 2021,
`delta-io/delta-sharing`, Apache-2.0), which established that an open sharing
protocol could win cross-vendor adoption. OpenSharing inherits the zero-copy +
short-lived-credential-vending model and the implementer ecosystem, and extends
the protocol beyond a single table format to be format- and asset-general, under
neutral governance. The Technical Charter was adopted June 9, 2026 (OpenSharing a
Series of LF Projects, LLC).
+
*Ongoing development:* The specification is developed openly at
`github.com/OpenSharing-IO/OpenSharing` under Apache-2.0.
+
Repo metrics as of Aug 26, 2026: 149 GitHub stars, 16 forks, 4 contributors.

* *Statement on alignment with LF AI's mission.*
+
LF AI & Data hosts the open building blocks of the AI and data stack — formats
(ONNX, Delta Lake), catalogs (Unity Catalog, Amundsen), lineage (OpenLineage,
Marquez), and stores (Milvus, Feast). None of them define how an asset crosses an
*organizational* boundary. OpenSharing is the interchange layer between those
building blocks, and it is governed rather than proprietary. Vendor-neutral
governance is a precondition for adoption of a sharing protocol, not a
nice-to-have.
